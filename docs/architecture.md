# Architecture

`src/main.tsx` mounts the React app. `src/App.tsx` coordinates the measured project, route worker and screen state. Reusable number fields and obstacle editor live in `src/ui/Fields.tsx`. The canvas is an SVG floorplan. Locale dictionaries are separate files in `src/locales` and are checked for key parity.

`schema.ts` validates untrusted documents. Schema version 1 stores centred doorways. Version 2 adds optional doorway offsets, and import validation requires the document and project versions to match. Draft recovery uses the same validation. `geometry.ts` calculates oriented furniture corners, doorway jambs and pose clearance. Doorway offsets are measured along the wall axis, and the jamb rectangles remain positive at narrow openings. `verify.ts` certifies a motion interval by bounding every point's displacement from the midpoint and recursively bisecting uncertified intervals. `search.ts` uses a deterministic bounded A* lattice and re-verifies the simplified route. `serialize.ts` validates saved routes, writes project JSON and creates a dimensioned SVG. `worker.ts` runs searches and import verification outside the interface thread. Each run has a generation identifier so stale messages cannot restore a route after an edit.

Vite bundles fonts locally and uses relative asset links. `public/sw.js` caches same-origin application files and supports repository path deployment under `/Unwedged/`. The service worker enables offline use after a successful first load. The app shows its "Offline ready" indicator only after the worker is active and controlling the page, so wait for that indicator before relying on offline use. No runtime network service is part of the app.

The editor keeps grouped project history for Undo and Redo. Measurement drafts autosave to browser storage and can be recovered on the next visit. Route results are not stored in drafts. If storage access fails, the editor continues in memory and offers Save project as a file fallback. The mobile Measurements panel exposes the obstacle editor on narrow screens.
