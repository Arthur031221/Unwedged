# Usage

Choose Apartment hallway, Corner landing or Blocked corridor. Edit floor dimensions and enter the furniture length, width, fixed carry height and safety margin. Set start and destination positions and angles with the fields or canvas tools. Select a wall or obstacle to move it or edit its dimensions. Walls can have one doorway with editable width, height and offset along the wall.

Choose New empty plan to start with a blank layout, then enter its name in Plan name. Creating the plan is one Undo step. Plan names autosave with measurements, and renaming a plan keeps a verified route. Find route is beside the plan and changes to Cancel search while a search is running. It starts a bounded search in a worker. Fine search uses a 5 cm and 5 degree lattice instead of 10 cm and 10 degrees. Use the transport slider or play button to inspect poses. Any geometry edit clears the current route. Undo and Redo restore grouped measurement edits.

Headings follow the selected centimetre or inch display unit. Export route sheet includes the plan name in its SVG caption. Measurements autosave locally and can be recovered on the next visit. Autosaved drafts contain measurements, not routes. If browser storage is unavailable, use Save project to download a copy. Open project validates input and checks a saved route before display. A successful open is undoable. If an import is rejected, the current plan and its certified route remain in place. Share encodes the document in the URL hash. The app reports when the link was copied to the clipboard. If clipboard access is blocked or unavailable, the link stays in the address bar and the app reports that separately. Opening a shared plan preserves your saved draft until you edit the shared plan. An invalid share link falls back to your saved measurements. Export route sheet writes a dimensioned SVG of the currently certified route.

A numeric measurement commits its complete value when you leave the field or press Enter. Invalid values receive visible accessible feedback and block search, sharing, saving and export until corrected. Editing wall dimensions preserves measured doorway width and offset. Conflicting dimensions are rejected. Keyboard users can edit numerical fields. On small screens, open the Measurements panel to edit obstacles. Units switch between centimetres and inches while stored values remain centimetres.

To create a wall or doorway, choose Draw obstacle and click the floor plan. Select the new piece, set Structure type to Wall, and enable Doorway. Enter the opening width, height and offset. An offset moves the opening along the wall's longer axis. Offset files use schema version 2 and older clients reject them. Centred version 1 files remain accepted.

A route is conditional on the entered measurements and 2D model. Search limits may miss a route. Read [accuracy and limits](accuracy.md) before treating a route as a building measurement guarantee.
